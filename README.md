### Hi, I'm Olive 👋

I build **[The Code Translator](https://thecodetranslator.com)**, a free online tool that translates binary, Morse and other codes to text and back. It runs entirely in your browser, needs no sign-up, and nothing you type is uploaded.

**Try it:** `01001000 01101001` → **Hi** · [Open the binary code translator](https://thecodetranslator.com/binary-code-translator/)

#### 🔧 Tools

- [Binary code translator](https://thecodetranslator.com/binary-code-translator/): paste 0s and 1s, get text back
- [Text to binary converter](https://thecodetranslator.com/binary-code-translator/text-to-binary/): turn any message into 8-bit binary
- [Binary alphabet chart](https://thecodetranslator.com/binary-code-translator/alphabet/): A to Z in binary, with a printable PDF
- [Binary to ASCII converter](https://thecodetranslator.com/binary-code-translator/binary-to-ascii/): each character with its ASCII code
- [Words in binary](https://thecodetranslator.com/binary-code-translator/words/): common words already written in binary
- [How to read binary](https://thecodetranslator.com/binary-code-translator/how-to-read-binary/): decode binary by hand, step by step
